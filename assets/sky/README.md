Drop-in sky photos (optional).

Put wide, horizontally tileable cloud images with transparent sky here and the game uses
them instead of its generated clouds:

- clouds_high.png  (thin high cloud, e.g. cirrus)
- clouds_mid.png   (cumulus)
- clouds_low.png   (haze or low cloud along the horizon)

Use images you have the rights to (your own photos, or CC0 sources such as Poly Haven).
